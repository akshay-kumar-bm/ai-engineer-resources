# AI Engineer Resources

A curated, link-first cheat sheet of tools, frameworks and learning resources for AI engineers and ML practitioners.

## What it is
A single-file reference list (no code). It groups the tools I reach for when building LLM and agent applications, with a one-line description and URL for each entry.

## Contents
- **Development tools**: version control, terminals/CLI, package managers (Git, GitHub, Copilot, npm, pip, Conda, Poetry, ...)
- **AI/ML frameworks**: LLM providers and frameworks (OpenAI, Anthropic, HuggingFace, LangChain, LlamaIndex, Ollama), classic ML/DL (PyTorch, TensorFlow, scikit-learn, XGBoost, FastAI), computer vision and NLP
- **Editors and IDEs**, plus VS Code extensions
- **Productivity tools**: notes, project management, diagramming, communication
- **Documentation and learning**: official docs, learning platforms, blogs
- **Agent building resources**: frameworks, design patterns, key components
- **Prompt engineering**: techniques (system prompts, role-based, chain-of-thought, few-shot, ...)
- **Data science tools** and **cloud platforms**

## Structure
```
README.md   # the entire resource list with table of contents
```

## Usage
Open `README.md` on GitHub and use the table of contents to jump to a section.

## Limitations / future work
- Links are not checked for freshness; some descriptions are generic.
- No opinions or ranking, just a directory. Adding short "when to use" notes per tool would make it more valuable.
